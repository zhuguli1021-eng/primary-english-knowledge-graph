# 小学英语知识图谱（小升初方向）

参照 [Marble os-taxonomy](https://github.com/withmarbleapp/os-taxonomy) 的“知识点 + 先修边”结构，做的一份小学英语知识库：知识点之间自动关联，按年级匹配难度出题，回收错题后沿先修关系找根因，给出点评和针对性训练。

**用法：** 双击 `app/index.html` 即可打开（图谱需要联网加载 cdnjs 上的 Cytoscape；出题和诊断离线也能用）。

## 里面有什么

| 内容 | 数量 | 文件 |
|---|---:|---|
| 知识点（语音、词汇、词法、时态、句法、交际、阅读、写作） | 101 | `data/topics.json` |
| 先修关系（hard 必须先学 / soft 建议先学，每条带理由） | 180 | `data/dependencies.json` |
| 真题共考关联（从真题自动算出） | 26 | `data/exam_stats.json` 的 `related` |
| 真题考频（每个知识点在多少份真卷出现、真题例句） | 239 份 | `data/exam_stats.json` |
| 题库（选择 + 填空 + 短文） | 522 | `data/questions/*.txt` → `data/questions.json` |
| 年级画像、难度规则、课标词表 | — | `data/levels.json`、`data/wordlists.json` |

每个知识点有：说明、掌握标准、孩子常见错误、教学建议、首学年级、课标出处、考频等级（必考/常考/偶考）。

## 数据来源

- **课标：** 《义务教育英语课程标准（2022年版2025年修订）》。二级（5~6 年级）505 词、三级 1600 词、不规则动词表由脚本从标准文本抽取；语法项目对照附录 4。标准文本来自第三方转载，未与教育部 PDF 逐页核对。
- **真题：** 你给的 103 套 Word 版分班/入学真卷，加上 4 本扫描 PDF（励志果、27 套真题、百校联盟专卷、最新小升初）的 OCR 文本，每 4 页算一份，合计 239 份。原文在 `corpus/`。
- **参考：** [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy) 的小学英语部分（208 个按 PEP 单元划分的点）。只参考了结构和对齐方式，没有复制它的数据（它是 CC BY-NC 许可）。本库按“小升初考点”划分，更适合分班考。

## 怎么保证题目难度匹配

1. **年级画像：** 每个年级规定了可用词表、单句最长词数、已学语法和题型风格。三四年级用核心词；五六年级用课标 505 词加 PEP 常用词（课标允许各地增加 100~300 词）；小升初再加三级词表，超出二级的词不超过 6%，而且要加中文注释。
2. **知识点不超前：** 只出首学年级不晚于孩子年级的点。
3. **难度随“学过多久”调整：** 刚学的点出基础/标准题；学过一年的点出全部三档；学过两年以上的点不再出基础题，避免太简单。
4. **自动质检（`kb.py check`）：** 答案必须在选项里，选项和题干不能重复；题干、短文和正确选项不能超出该年级词表，单句不能超长；先修关系不能成环，“必须先学”的点不能晚于本点。网页里导入 AI 题时走同一套检查。
5. **人工复核：** 全部 522 题逐题看过答案，修掉了 6 道有歧义或事实错误的题。

## 常用命令

```bash
python3 scripts/kb.py questions        # 题库文本 → questions.json
python3 scripts/kb.py check            # 质检
python3 scripts/kb.py stats corpus     # 重新统计真题考频和共考关联
python3 scripts/kb.py prompt te.past_simple 6 2 5   # 生成给 AI 的出题提示词
python3 scripts/kb.py select 7 20      # 按小升初抽一套题看看
python3 scripts/kb.py bundle           # 打包给网页用
```

**改题：** 直接编辑 `data/questions/*.txt`。每行一道题，格式是 `[年级/难度] 题干 | A 选项 | B 选项 | =答案 | 解析`，然后依次运行 `questions`、`check`、`bundle` 三条命令。

## 阅读与书面表达

- **阅读按新课标趋势分四类题材：** 应用文、科普跨学科、中国文化、记叙情感。每篇短文都标了题材；改编自真实报道的，标出原报道链接。
  - **新闻改编篇：** 神舟二十三号、巩义少年学非遗、三门峡大天鹅、大熊猫赴亚特兰大，素材来自 China Daily、Wikipedia、河南省政府网和美联社的报道。正文是按年级词表重写的原创短文，没有照抄原句。
  - **其余短文：** 原创。
- **阅读题少考“原文照抄”：** 新增「篇章结构与段落作用」「作者意图、观点态度与人物情感」两个知识点。每篇短文都搭配细节、词义猜测、推理判断，以及主旨或结构题。
- **书面表达：** 13 道，话题来自真卷常见题：日常生活、家人朋友、经历、梦想、书信、健康建议、传统文化和家乡。每道都有要点、好句和范文，范文按年级词表检查过。
  - **在线作答：** 实时统计词数。
  - **打印卷：** 留出作文横线。
  - **答案卷：** 带范文和评分标准（10 分、五档）。
- **作文批改：** 接入模型后，交卷时自动按五档标准打分。批改会给出优点、漏掉的要点、逐条改错和修改稿，每条错误都关联到知识点（比如 "I gets up" 计入「一般现在时」），一起进入诊断和针对性训练。不接模型时，老师可以在「老师录入对错」里直接给作文打分。
- **按真卷结构组卷：** 卷子分为单项选择、完形填空、阅读理解（2~3 篇不同题材）、词汇运用、书面表达几部分。
- **AI 出题新增两种题型：**
  - **阅读理解篇章：** 选题材，可以粘贴新闻原文或要点，AI 会改写成适合该年级的原创短文并出题；出完的题同样经过盲解复核。
  - **书面表达：** AI 出题目并写范文，范文会按年级词表检查。

## 接大模型直接出题

网页「AI 出题」页可以选四种出题方式：

| 方式 | 在哪用 | 要不要密钥 |
|---|---|---|
| Claude（内置） | 在线版链接 | 不要，用你自己的 Claude 账号额度；第一次使用时页面会请你允许 |
| 本机 llm.json 配置的模型 | 本地版，用 `kb.py serve` 打开 | 密钥只放在 `llm.json` 里，浏览器拿不到 |
| OpenAI 兼容接口 | 本地版 | 填在网页里，只保存在这台电脑的浏览器里。DeepSeek、通义千问、Kimi、智谱、豆包、OpenAI 都可以，下拉框里有预设 |
| Anthropic Claude API | 本地版 | 同上 |

在线版不允许访问外部网址，所以自定义接口只在本地版可用。

**盲解复核（默认开启）：** 出完题后，再让模型在看不到答案的情况下把题做一遍。答案对不上、或者模型认为有歧义的题，一律不入库。网页导入的题还是只存在这台电脑的浏览器里。

**本地版启动方法：** 把 `llm.example.json` 复制成 `llm.json`，填好接口和密钥（这个文件不要发给别人），然后运行下面的命令，再在浏览器打开 http://localhost:8765 。

```bash
python3 scripts/kb.py serve
```

**命令行批量出题：** 结果会写进 `data/待审题目/`。老师审过后，把题挪到 `data/questions/` 里，再依次运行 `questions`、`check`、`bundle` 三条命令。

```bash
python3 scripts/kb.py generate te.past_simple 6 2 5
```

## 网页功能

- **知识图谱：** 横向按首学年级（三年级 → 小升初），纵向按领域。圆越大表示考频越高。点一个知识点能看说明、易错点、先修和后续，以及真题例句。勾选后可以按学生掌握情况着色。
- **出题组卷：** 选年级、题数和范围，自动按考频加权抽题；短文题整组带出。可以在线作答，也可以打印学生卷和答案卷。
- **诊断与训练：** 孩子在线作答，或者老师勾选纸质卷的对错。系统按知识点统计得分，沿先修边找根因：薄弱点的先修点也薄弱，就先补先修点；没测过的先修点建议补测。然后生成老师点评（含易错点和教学建议）。训练是自适应的：连对两题升一档难度，答错降一档；基础题也错，就回到它的先修点。
- **AI 出题：** 生成带年级约束的提示词，可以交给任何 AI。AI 返回的 JSON 粘回网页后自动质检再入库。

## 局限

- 知识点粒度和先修关系是 AI 起草的，**需要一线老师审核**。
- 考频靠关键词和选项识别统计，是近似值。扫描件的 OCR 中文识别较差，每 4 页算一份也只是估计。
- 机检只能查格式、词汇和句长，查不出“答案本身对不对”。AI 新出的题要老师确认后再用。
- 学生成绩和导入的题只保存在当前浏览器里，换电脑不会同步。
- 没有听力题，写作只有选择形式的规范题，没有作文批改。
