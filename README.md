# 小学与初中英语知识图谱

参照 [Marble os-taxonomy](https://github.com/withmarbleapp/os-taxonomy) 的“知识点 + 先修边”结构，做的一份小学英语知识库：知识点之间自动关联，按年级匹配难度出题，回收错题后沿先修关系找根因，给出点评和针对性训练。

**用法：** 首次在教师电脑执行 `python3 scripts/kb.py bundle`，再双击 `app/index.html` 打开（图谱需要联网加载 cdnjs 上的 Cytoscape；出题和诊断离线也能用）。

## 里面有什么

| 内容 | 数量 | 文件 |
|---|---:|---|
| 知识点（语音、词汇、词法、时态、句法、交际、阅读、写作） | 106 | `data/topics.json` |
| 先修关系（hard 必须先学 / soft 建议先学，每条带理由） | 193 | `data/dependencies.json` |
| 真题共考关联（从真题自动算出） | 54 | `data/exam_stats.json` 的 `related` |
| 语料库与分年级考频（含 3~6 年级同步/期末卷 + 小升初真卷） | 470 份（有效统计 460 份） | `corpus/`、`data/corpus_index.json`、`data/exam_stats.json` |
| 真题题目库与年级真卷蓝图（AI 仿写母题来源） | 10,490 小题 + 620 篇章/作文 | `data/exam_items.json`、`data/exam_blueprint.json` |
| 正式题库（选择 + 填空 + 短文 + 书面表达） | 577 | `data/questions/*.txt` → `data/questions.json` |
| 年级画像、难度规则、课标词表 | — | `data/levels.json`、`data/wordlists.json` |

每个知识点有：说明、掌握标准、孩子常见错误、教学建议、首学年级、课标出处、考频等级（必考/常考/偶考）。

## 数据来源

- **课标：** 《义务教育英语课程标准（2022年版2025年修订）》。二级（5~6 年级）505 词、三级 1600 词、不规则动词表由脚本从标准文本抽取；语法项目对照附录 4。标准文本来自第三方转载，未与教育部 PDF 逐页核对。
- **语料库与真题：** 原 239 份河南小升初/分班真卷，加上新导入的 231 份 3~6 年级人教 PEP 同步/期中/期末/名校真卷及 2027 小升初分类卷、郑州小升初名校 AK 真题卷，合计 **470 份**（其中 460 份非答案卷参与考频统计，拆出 **10,490 道真题小题** 和 **620 个篇章/作文大题** 供 AI 仿写）。原文在 `corpus/`，索引在 `data/corpus_index.json`。
- **人教教材目录**的数据来源与使用范围见下节。

## 按年级、册次和单元找知识点

在网页打开 **教材目录**，依次选择年级、上下册和单元。每项列出学习目标、适用词语和关联考点。点击关联考点可查看原图谱，在考点详情展开「教材单元与细目」可返回对应课次。

目录覆盖参考版本的 532 项英语学习要求，其中小学三至六年级 275 项、初中七至九年级 257 项。467 项有具体单元位置（含预备和复习），65 项在所属册标记为「单元待核」。该版本没有单列九年级下册。单元位置沿用参考库记录，待核说明见[参考库核对记录](https://github.com/xiaoyang111222/cn-math-taxonomy/blob/601356aa39a9770e979819889846f6885ca9a468/docs/english-pending-classification-20261112.md)。

目录保存于 `data/curriculum.json`。其中每个来源编号只出现一次，每个位置可引用原考点、已有 CPP 单元目标或新增细目。细目通过 `parents` 关联上级考点或领域；同一技能在不同单元可以有不同学习任务和例词。教材年级与考点的首学年级分别记录。出题与诊断继续使用已有年级画像、母题与题库。

教材位置、来源编号、名称和词语参照 [xiaoyang111222/cn-math-taxonomy 的固定版本](https://github.com/xiaoyang111222/cn-math-taxonomy/tree/601356aa39a9770e979819889846f6885ca9a468)，其材料采用 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)。本项目重新撰写学习目标并整理跨册关联。参考材料的商业使用按原项目授权说明办理。

```bash
python3 scripts/kb.py curriculum --grade 6 --semester 上 --q 零花钱
python3 scripts/kb.py curriculum --topic te.present_continuous
```


## 教师单元作业生成器

在「出题组卷」选择课程级别、单元和卷型。综合卷直接生成，专项卷另选一个板块。一次生成 L、M、H 三套，预览页可切换档位、换一题、删除、补题，或重抽当前卷及全部三套。

G0 对应 5–6 岁，G1 对应 6–8 岁，G2 对应 8–10 岁。表中的年级指原卷来源。三个档位均按孩子的年龄、单元词汇和整题阅读量筛选。G0 卷提供可由大人朗读的一步指令，可让孩子指选或口答。缺少适龄原题时，教师页显示待补充，有题的板块仍可使用。

| CPP 级别 | L 原卷年级 | M 原卷年级 | H 原卷年级 | 综合卷结构 |
|---|---|---|---|---|
| G0、G1 | 三年级 | 四年级 | 五年级 | 语音 2、词汇 5、语法 10、情景交际 2、阅读 1 |
| G2 | 四年级 | 五年级 | 六年级 | 词汇 5、语法 10、情景交际 2、阅读 1 |
| G3 | 五年级 | 六年级 | 小升初 | 词汇 5、语法 10、情景交际 2、阅读 1 |

每套专项默认 10 道，交际每道保留五小题，阅读按整篇计数。候选按整单元的语法、句型、主题、四组核心词和拼读规则匹配，只收有答案依据的公立校原题。板块不足时显示当前题数，教师可以直接使用已有题目。三套批量导出时，每份有题的卷子各自成为一个文件，共同打包为 ZIP。PDF 为 A4 打印版，Word 为可编辑的 DOCX，每份作业在末尾另起一页附教师答案。

**教师电脑首次使用**　在仓库根目录运行下列命令。题库索引保存在本机 `data/teacher-homework.js`；该文件不随 Git 同步。

```bash
python3 scripts/kb.py bundle
node --test tests/unit-homework.test.cjs
```

**机构网页入口**　网页从同源 `/api/teacher/homework` 读取组卷题库，服务端逐次核验教师账号。本地文件版按教师电脑的文件访问权限使用。新教师可用下列命令登记，密码在终端交互输入，账号文件放在仓库外。机构内网部署由网关提供 HTTPS，将此接口转发到本机服务；其余教研开发 API 保持本机访问。

```bash
export CPP_TEACHER_ACCOUNTS="$HOME/.cpp-teachers.json"
python3 scripts/kb.py teacher-add teacher01
python3 scripts/kb.py serve
```

教师版的抽题配置在 `scripts/homework_bank.py`。语料的原卷配套答案按卷名、板块和题号关联，补充核对的原题答案在 `data/homework_reviewed_keys.json`。教研后台的命题工具和模型配置独立于教师作业生成器。

## 怎么保证题目难度匹配

1. **年级画像：** 每个年级规定了可用词表、单句最长词数、已学语法和题型风格。三四年级用核心词；五六年级用课标 505 词加 PEP 常用词（课标允许各地增加 100~300 词）；小升初再加三级词表，超出二级的词不超过 6%，而且要加中文注释。
2. **知识点不超前：** 只出首学年级不晚于孩子年级的点。
3. **难度随“学过多久”调整：** 刚学的点出基础/标准题；学过一年的点出全部三档；学过两年以上的点不再出基础题，避免太简单。
4. **自动质检（`kb.py check`）：** 答案必须在选项里，选项和题干不能重复；题干、短文和正确选项不能超出该年级词表，单句不能超长；先修关系不能成环，“必须先学”的点不能晚于本点。
5. **人工复核：** 全部 522 题逐题看过答案，修掉了 6 道有歧义或事实错误的题。

## 常用命令

```bash
python3 scripts/kb.py import <试卷目录>            # 导入新试卷文字版到 corpus/ 并更新索引
python3 scripts/kb.py items                        # 拆成真题题目库 exam_items.json 与年级蓝图
python3 scripts/kb.py stats                        # 重新统计分年级考频、考法分布和共考关联
python3 scripts/kb.py topics --grade 6             # 查看某年级知识点考频与高频题型
python3 scripts/kb.py exemplars te.past_simple 6   # 查看该知识点在该年级的真题母题
python3 scripts/kb.py blueprint 6                  # 查看该年级真卷大题结构
python3 scripts/kb.py task te.past_simple 6 2 5 --qtype 适当形式  # 为 Codex/WorkBuddy 创建仿真题任务
python3 scripts/kb.py generate te.past_simple 6 2 5 --provider codex  # 直接用本地 Codex 或 API 出题
python3 scripts/kb.py serve                        # 启动本地网页 + HTTP API（http://localhost:8765）
python3 scripts/kb.py mcp                          # 启动 stdio MCP 服务（Codex/WorkBuddy/Claude Code）
python3 scripts/kb.py questions                    # 题库文本 → questions.json
python3 scripts/kb.py check                        # 质检
python3 scripts/kb.py select 7 20                  # 按该年级真题考频加权抽一套题
python3 scripts/kb.py bundle                       # 打包给网页用（含精简母题包与蓝图）
```

详细接口与本地智能体接入（Codex / WorkBuddy / MCP / HTTP API）见 `docs/API.md` 和 `AGENTS.md`。

**改题：** 直接编辑 `data/questions/*.txt`。每行一道题，格式是 `[年级/难度] 题干 | A 选项 | B 选项 | =答案 | 解析`，然后依次运行 `questions`、`check`、`bundle` 三条命令。

## 阅读与书面表达

- **阅读按新课标趋势分四类题材：** 应用文、科普跨学科、中国文化、记叙情感。每篇短文都标了题材；改编自真实报道的，标出原报道链接。
  - **新闻改编篇：** 神舟二十三号、巩义少年学非遗、三门峡大天鹅、大熊猫赴亚特兰大，素材来自 China Daily、Wikipedia、河南省政府网和美联社的报道。正文是按年级词表重写的原创短文，没有照抄原句。
  - **其余短文：** 原创。
- **阅读题少考“原文照抄”：** 新增「篇章结构与段落作用」「作者意图、观点态度与人物情感」两个知识点。每篇短文都搭配细节、词义猜测、推理判断，以及主旨或结构题。
- **书面表达：** 13 道，话题来自真卷常见题：日常生活、家人朋友、经历、梦想、书信、健康建议、传统文化和家乡。每道都有要点、好句和范文，范文按年级词表检查过。
  - **在线作答：** 实时统计词数。
  - **打印卷：** 留出作文横线。
  - **答案卷：** 带范文和评分标准（10 分、五档）。
- **作文批改：** 接入模型后，交卷时自动按五档标准打分。批改会给出优点、漏掉的要点、逐条改错和修改稿，每条错误都关联到知识点（比如 "I gets up" 计入「一般现在时」），一起进入诊断和针对性训练。不接模型时，老师可以在「老师录入对错」里直接给作文打分。
- **按真卷结构组卷：** 卷子分为单项选择、完形填空、阅读理解（2~3 篇不同题材）、词汇运用、书面表达几部分。
- **AI 出题新增两种题型：**
  - **阅读理解篇章：** 选题材，可以粘贴新闻原文或要点，AI 会改写成适合该年级的原创短文并出题；出完的题同样经过盲解复核。
  - **书面表达：** AI 出题目并写范文，范文会按年级词表检查。

## 接大模型直接出题

教研人员可在本机使用 `kb.py task`、`kb.py generate` 和 `kb.py ingest` 进行独立的题库建设。模型与接口设置见 `llm.example.json` 和 `docs/API.md`。教师作业抽取原卷时无需接入模型。

## 网页功能

- **知识图谱：** 横向按首学年级（三年级 → 小升初），纵向按领域。圆越大表示考频越高。点一个知识点能看说明、易错点、先修和后续，以及真题例句。勾选后可以按学生掌握情况着色。
- **出题组卷** 提供教师单元综合卷、专项卷、分层预览和打印文件。
- **诊断与训练** 可在知识图谱点击「练这个点」开始训练，按作答记录查看知识点掌握情况和后续练习建议。

## 局限

- 知识点粒度和先修关系是 AI 起草的，**需要一线老师审核**。
- 考频靠关键词和选项识别统计，是近似值。扫描件的 OCR 中文识别较差，每 4 页算一份也只是估计。
- 机检只能查格式、词汇和句长，查不出“答案本身对不对”。AI 新出的题要老师确认后再用。
- 学生成绩和导入的题只保存在当前浏览器里，换电脑不会同步。
- 没有听力题，写作只有选择形式的规范题，没有作文批改。
