### 七、如何管理零花钱是每个孩子都需要学习的。（10 分）

Pocket money is important for us, so we need to use it wisely. First, we should make a spending plan. We can list things we need and things we want. For example, we need to buy school things like dictionaries, but we may want to buy toys and snacks.

Before buying everything, we should ask ourselves some questions: Do I need it now? Do I already have one? Is it expensive? Do I have enough money? If something is expensive, we can wait for a sale to save money. We can also save some pocket money for big things, like a computer or a microscope.

It’s good to share our money with others too. We can buy nice gifts for our family. By making good plans, we can learn to save and spend money wisely.
